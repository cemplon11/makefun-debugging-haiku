A pure-stdlib Python program that writes one haiku about debugging: a red
breakpoint waits, the log swears nothing has changed, and the last line turns
it — one moved line. Three lines in the 5-7-5 shape, 79 characters in total,
no trailing newline. Running `python3 main.py` writes the haiku to
`/output/entry.txt`, deterministically, with no network and no third-party
packages.

## Run it

```sh
python3 main.py
```
